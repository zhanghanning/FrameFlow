# 注册、岗位申请与项目权限

## 账号与岗位

注册 → 自动建立个人创作者档案并赋予 CREATOR → 登录工作台 → 申请附加岗位 → 管理员审批 → 当前会话获得岗位权限。

每次申请一个岗位，填写申请理由。可申请 ADMIN（管理员）、PRODUCER（项目统筹）、FINANCE（财务）、REVIEWER（审核）。申请记录保存审批人、意见及时间；待审批申请不授予权限，同一岗位的待审批申请不重复提交。拒绝后可重新申请，管理员本人申请由其他管理员审批。

管理员可直接管理团队岗位。已有创作者账号保留档案、素材归属和历史分账；撤回附加岗位后继续作为创作者使用。账号停用后已有会话和新登录均失效。所有请求按数据库中当前身份判断权限。

## 职责与范围

| 身份 | 业务职责 | 范围 |
|---|---|---|
| 创作者 CREATOR | 管理个人资料、平台账号和素材，参与作品创作与发布，查看个人收益 | 本人资料与资产、参与项目、个人分账付款；共同结算依据可读 |
| 项目统筹 PRODUCER | 立项、安排成员和进度、组织作品与发布、登记项目成本 | 本人负责项目；素材需明确授权给该项目，素材元数据仍由所有者管理；成本列表为本人登记 |
| 财务 FINANCE | 收入录入、CSV导入、对账、合同分成、生成和提交结算、付款登记 | 工作室财务全量，生产信息可读 |
| 审核 REVIEWER | 核查依据、审批成本、批准或退回结算、查看日志 | 工作室业务可读，按职责执行审批 |
| 管理员 ADMIN | 岗位审批、账号管理、项目移交及各业务管理 | 工作室全量；结算和成本仍遵守提交与审核分离 |

岗位可以兼任。创作者兼任统筹时，可以制作本人参与或负责项目的作品，但只有负责项目可以调整成员、进度及登记统筹成本；本人财务范围保持个人。财务或审核身份提供全量读取，生产写入仍按本人资产、参与项目及统筹负责项目判断。

## 项目关系

每个项目有一位主要统筹、多个参与创作者；同一创作者可以参与多个统筹负责的项目。项目负责人由账号引用，项目成员关联创作者档案。统筹自行立项时负责人固定为本人，管理员可以指定或移交给有效管理员/统筹账号。

创作者通过项目协作，不永久隶属于某位统筹。项目成员是参与关系；获得分成及比例由生效分账协议决定。

## 素材项目授权

素材所有者可将素材授权给自己参与或负责的项目，管理员可管理全部授权。项目统筹和成员可以读取、引用该项目已获授权素材，修改和归档仍由素材所有者或管理员执行。

保存作品时，使用本人素材会自动建立该目标项目的授权；使用第三方素材须已有目标项目授权。某素材在项目甲可用，不会自动允许项目乙引用。已有作品使用的项目授权须保留，授权日期与发布平台限制继续生效。

历史作品引用在增量初始化时补为项目素材授权。旧 USER 基础账号迁移为创作者；原有岗位和业务记录保留。

## 相关实现

- Register.vue、Profile.vue：注册、个人账号和创作者资料入口。
- RoleApplications.vue：本人申请、管理员审核、历史结果。
- Projects.vue、Works.vue、Assets.vue：项目职责和素材授权操作。
- AuthController / AuthService / AuthMapper：注册事务、申请审批和当前岗位。
- StudioService / StudioMapper / AssetService：负责人、成员和项目素材授权范围。
- database/identity-workflow.sql：保留已有数据的增量迁移。
- scripts/verify_registration.py：注册、四类岗位申请、项目归属、素材授权及即时权限验证。
